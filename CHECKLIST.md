# Чеклист выполнения проекта

## Критерий 1: Инфраструктура (6 баллов)

- [ ] Minikube установлен
- [ ] Кластер запущен с 2 нодами
- [ ] Скриншот вывода `minikube status`
- [ ] Скриншот вывода `kubectl get nodes`
- [ ] Ingress addon включен
- [ ] Metrics-server addon включен

**Команды для проверки:**
```bash
minikube status
kubectl get nodes
minikube addons list
```

## Критерий 2: Контейнеризация (8 баллов)

- [ ] Dockerfile создан и корректен
- [ ] Docker образ собран
- [ ] Размер образа < 150MB
- [ ] REST API эндпоинт `/api/sentiment` работает
- [ ] Скриншот Dockerfile
- [ ] Скриншот размера образа (`docker images`)
- [ ] Скриншот кода эндпоинта
- [ ] Скриншот работы API (curl запрос и ответ)

**Команды для проверки:**
```bash
docker build -t sentiment-analyzer:latest .
docker images sentiment-analyzer:latest
curl "http://localhost:8080/api/sentiment?text=hello"
```

## Критерий 3: Развертывание в Kubernetes (8 баллов)

- [ ] Deployment создан с 3 репликами
- [ ] Service типа LoadBalancer создан
- [ ] Ingress настроен
- [ ] HPA настроен по CPU
- [ ] Все 3 пода запущены и работают
- [ ] Скриншот YAML Deployment
- [ ] Скриншот YAML Service
- [ ] Скриншот YAML Ingress
- [ ] Скриншот YAML HPA
- [ ] Скриншот запущенных подов (`kubectl get pods`)

**Команды для проверки:**
```bash
kubectl get deployment sentiment-analyzer
kubectl get service sentiment-analyzer-service
kubectl get ingress sentiment-analyzer-ingress
kubectl get hpa sentiment-analyzer-hpa
kubectl get pods -l app=sentiment-analyzer
```

## Критерий 4: Мониторинг (10 баллов)

- [ ] Prometheus установлен через Helm
- [ ] Grafana установлен
- [ ] ServiceMonitor применен
- [ ] Метрики доступны на `/actuator/prometheus`
- [ ] Дашборд Grafana создан и работает
- [ ] Скриншот Prometheus UI
- [ ] Скриншот дашборда Grafana
- [ ] Скриншот метрик приложения

**Команды для проверки:**
```bash
kubectl get pods -n monitoring
kubectl port-forward -n monitoring svc/prometheus-kube-prometheus-prometheus 9090:9090
kubectl port-forward -n monitoring svc/prometheus-grafana 3000:80
curl http://localhost:8080/actuator/prometheus
```
